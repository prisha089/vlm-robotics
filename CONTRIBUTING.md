# Contributing

## Workflow
1. `git checkout main && git pull`
2. `git checkout -b <type>/<short-name>` (types: feature, data, analysis, fix)
3. Commit small, clear changes and push your branch
4. Open a pull request, write `Closes #<issue>`, and request a reviewer
5. Merge after 1 approval; the branch deletes automatically

## Rules
- Never commit data, model weights, or API keys
- Every task has a GitHub Issue with a "Done when" condition
- Pull `main` before starting new work
- Ask in the team chat if you're blocked for more than a day
